# 🚀 Homelab Journey

Documentación y bitácora de aprendizaje sobre la configuración, administración y despliegue de mi propio servidor local (homelab) 24/7.

## 📌 Objetivos del Proyecto
- Aprender sobre administración de sistemas (Linux).
- Orquestar infraestructura de contenedores utilizando **Coolify** (PaaS self-hosted).
- Configurar servicios de red y proxy inverso de forma automatizada.
- Mantener documentación detallada paso a paso.

## 📂 Estructura de la Documentación
Toda la documentación está dividida en módulos en la carpeta `/docs/`:

1. [Hardware y Sistema Operativo](./docs/01-hardware-y-os/README.md)
2. [Redes y Configuración](./docs/02-redes/README.md)
3. [Docker y Contenedores](./docs/03-docker/README.md)
4. [Servicios Desplegados](./docs/04-servicios/README.md)
5. [Acceso Remoto (Cloudflare Tunnels)](./docs/05-acceso-remoto/README.md)
